## Session handoff (KontextKit Lite)

- Session start: if `.agent/handoff.md` exists, read it first and confirm goal and next step in 2-3 lines.
- Never retry approaches listed under "Don't retry" in the handoff without new evidence.
- When the user says "handoff", or before the context gets long or the session ends: update `.agent/handoff.md` (handoff skill/command).
